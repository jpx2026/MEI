**sudo sysctl -w net.ipv4.ip_forward=1** - Isto ativa imediatamente o encaminhamento IPv4 no kernel Linux. Por defeito, uma máquina Linux pode ter duas interfaces de rede e comunicar por ambas, mas isso não significa automaticamente que encaminha tráfego entre elas.
sudo nano /etc/sysctl.d/99-router.conf 
net.ipv4.ip_forward=1
sudo sysctl --system
sysctl net.ipv4.ip_forward

sudo nft add table ip nat
sudo nft 'add chain ip nat postrouting { type nat hook postrouting priority 100; policy accept; }'
sudo nft add rule ip nat postrouting ip saddr 192.168.0.0/24 oifname "eth0" masquerade
sudo sh -c 'nft list ruleset > /etc/nftables.conf'
